Recap P01 & Indexing: loc vs iloc
C3.1

Di P01 kita sudah bisa membaca DataFrame dan melihat strukturnya. Sekarang kita perlu mengaksesnya dengan presisi — memilih baris tertentu, kolom tertentu, atau kombinasi keduanya. Inilah tugas loc dan iloc.

Recap Singkat P01 — Apa yang Sudah Kita Tahu

Python · pandas recap P01
import pandas as pd

df = pd.read_csv('dataset-bprs-p01.csv')
df.head()           # 5 baris pertama
df.info()           # tipe data tiap kolom
df.describe()       # statistik dasar kolom numerik
df.shape            # (20, 12) → 20 baris, 12 kolom
df.columns.tolist() # daftar nama kolom

loc — Label-Based Indexing

df.loc[baris, kolom] mengakses data berdasarkan nama label (nama index atau nama kolom). Ini adalah cara yang paling mudah dibaca manusia.

Python · df.loc[]
# --- Satu baris, satu kolom ---
df.loc[0, 'nama_bprs']           # → 'BPRS Al-Amin'

# --- Satu baris, beberapa kolom ---
df.loc[0, ['nama_bprs', 'kota', 'total_aset_juta']]

# --- Range baris (inklusif kedua ujung!) ---
df.loc[0:3, 'nama_bprs']           # baris 0,1,2,3 → 4 baris

# --- Semua baris, kolom tertentu ---
df.loc[:, ['nama_bprs', 'npf_persen', 'roe_persen']]
BPRS Al-Amin → nama_bprs baris 0 0 BPRS Al-Amin 1 BPRS Berkah Syariah 2 BPRS Mandiri Sejahtera 3 BPRS Amanah Insani
⚠️ Gotcha! Pada .loc[], range baris bersifat inklusif di kedua ujung. Jadi df.loc[0:3] menghasilkan 4 baris (0, 1, 2, 3) — berbeda dari Python slice biasa yang eksklusif di ujung kanan.

iloc — Position-Based Indexing

df.iloc[baris, kolom] mengakses data berdasarkan nomor posisi integer (seperti list Python). Range-nya mengikuti aturan Python standar — eksklusif di ujung kanan.

Python · df.iloc[]
# --- Baris ke-0, kolom ke-0 ---
df.iloc[0, 0]                  # → 'BPRS Al-Amin'

# --- Baris 0–2 (eksklusif 3), kolom 0–3 ---
df.iloc[0:3, 0:4]             # → 3 baris, 4 kolom

# --- 5 baris terakhir ---
df.iloc[-5:]                    # Negatif = dari belakang

# --- Kolom pilihan berdasarkan posisi ---
df.iloc[:, [0, 1, 7]]          # kolom ke-0, 1, 7
Aspeklociloc
Dasar pengaksesanLabel / namaPosisi integer
Range barisInklusif kedua ujungEksklusif ujung kanan
Cocok digunakanSaat nama index/kolom diketahuiSaat butuh posisi relatif
Contoh kolom'nama_bprs'0
💡 Rule of thumb: Gunakan loc untuk kode yang mudah dibaca orang lain (label eksplisit lebih jelas). Gunakan iloc ketika kamu butuh slice posisional atau saat nama kolom berubah-ubah.

Boolean Filtering & .query()
C3.2

Memfilter data adalah operasi paling sering dilakukan dalam analisis. pandas memiliki dua cara: boolean masking (sintaks Python murni) dan .query() (mirip SQL WHERE — lebih ringkas untuk kondisi kompleks).

Boolean Masking — Kondisi Tunggal

Python · boolean filtering dasar
# Filter: hanya BPRS dengan NPF < 3% (sehat)
mask_sehat = df['npf_persen'] < 3.0
df_sehat = df[mask_sehat]
print(df_sehat[['nama_bprs', 'npf_persen']])

# Singkat dalam satu baris:
df_sehat = df[df['npf_persen'] < 3.0]
nama_bprs npf_persen 2 BPRS Mandiri Sejahtera 1.8 4 BPRS Mitra Mentari 1.5 10 BPRS Tazkia Utama 1.9 13 BPRS Nusantara Mandiri 2.0 ... (12 BPRS dengan NPF < 3%)

Boolean Masking — Kondisi Majemuk

Python · kombinasi kondisi (& | ~)
# AND: NPF rendah DAN ROE tinggi (BPRS ideal)
df_ideal = df[(df['npf_persen'] < 2.5) & (df['roe_persen'] > 12)]

# OR: BPRS di Jawa Barat ATAU DKI Jakarta
df_jabodetabek = df[(df['provinsi'] == 'Jawa Barat') |
                    (df['provinsi'] == 'DKI Jakarta')]

# NOT: bukan dari Jawa Timur
df_bukan_jatim = df[~(df['provinsi'] == 'Jawa Timur')]

# .isin() — lebih ringkas untuk list nilai
provinsi_target = ['Jawa Barat', 'DKI Jakarta', 'Banten']
df_jabar_jkt = df[df['provinsi'].isin(provinsi_target)]
⚠️ Wajib pakai tanda kurung! Setiap kondisi dalam & atau | harus dibungkus tanda kurung. df[df['a'] > 1 & df['b'] < 5] akan error — yang benar: df[(df['a'] > 1) & (df['b'] < 5)]

.query() — Sintaks SQL-like yang Lebih Bersih

.query() menerima string ekspresi yang dievaluasi sebagai kondisi. Lebih ringkas dan mudah dibaca untuk kondisi kompleks.

Python · .query() method
# Setara dengan df[df['npf_persen'] < 3.0]
df.query('npf_persen < 3.0')

# Kondisi majemuk — jauh lebih bersih
df.query('npf_persen < 2.5 and roe_persen > 12')
df.query('provinsi in ["Jawa Barat", "DKI Jakarta"]')

# Gunakan @ untuk variabel eksternal
threshold_npf = 3.0
df.query('npf_persen < @threshold_npf')

# Chain dengan metode lain
(df.query('npf_persen < 3 and total_aset_juta > 50000')
   [['nama_bprs', 'kota', 'npf_persen', 'total_aset_juta']]
   .sort_values('total_aset_juta', ascending=False)
   .reset_index(drop=True)
)

C3.3

Pertanyaan bisnis seperti "Rata-rata NPF per provinsi?" atau "Total aset BPRS yang sudah berdiri >15 tahun?" memerlukan operasi Split → Apply → Combine. Di pandas, ini dilakukan dengan groupby().

Mekanisme Split–Apply–Combine

DataFrame Asli20 baris BPRS
→
Splitgroupby('provinsi')
→
Apply.mean() / .agg()
→
CombineHasil per provinsi
→
DataFrame BaruN baris (satu per grup)

groupby Dasar + Aggregasi Tunggal

Python · groupby + mean, sum, count
# Rata-rata NPF dan ROE per provinsi
df.groupby('provinsi')[['npf_persen', 'roe_persen']].mean()

# Jumlah BPRS per provinsi
df.groupby('provinsi')['nama_bprs'].count()

# Total aset per provinsi
df.groupby('provinsi')['total_aset_juta'].sum().sort_values(ascending=False)
provinsi Banten 83000 DKI Jakarta 62000 DI Yogyakarta 52000 Jawa Barat 276000 ← total aset tertinggi (5 BPRS) Jawa Timur 119000 ... Name: total_aset_juta, dtype: int64

.agg() — Multiple Aggregasi Sekaligus

Python · .agg() dictionary
# Berbeda fungsi untuk berbeda kolom

    rata_roe      = ('roe_persen',     'mean'),
    total_aset    = ('total_aset_juta','sum'),
    maks_car      = ('car_persen',     'max'),
    min_npf       = ('npf_persen',     'min'),
).round(2)

print(hasil.reset_index())

.transform() — Agregasi tanpa Mengecilkan DataFrame

Perbedaan kunci: .agg() menghasilkan DataFrame lebih kecil (satu baris per grup). .transform() menghasilkan Series dengan panjang sama seperti DataFrame asli — sangat berguna untuk membuat kolom baru.

Python · .transform() — membuat kolom baru
# Rata-rata NPF provinsi untuk setiap baris
df['rata_npf_provinsi'] = df.groupby('provinsi')['npf_persen'].transform('mean')

# Deviasi NPF dari rata-rata provinsinya
df['npf_deviasi'] = df['npf_persen'] - df['rata_npf_provinsi']

# BPRS yang NPF-nya di bawah rata-rata provinsinya → lebih baik dari peer
df_outperform = df[df['npf_deviasi'] < 0][['nama_bprs', 'provinsi', 'npf_persen', 'npf_deviasi']]
print(df_outperform)
nama_bprs provinsi npf_persen npf_deviasi 2 BPRS Mandiri Sejahtera Jawa Barat 1.8 -0.98 10 BPRS Tazkia Utama Jawa Barat 1.9 -0.88 3 BPRS Amanah Insani Jawa Timur 2.9 -0.35 ... (BPRS yang NPF-nya lebih baik dari rata-rata provinsinya)
💡 Insight bisnis: .transform() memungkinkan analisis komparatif — apakah kinerja suatu BPRS lebih baik atau lebih buruk dari peer-nya di provinsi yang sama? Pertanyaan ini tidak bisa dijawab hanya dengan agregasi biasa.

merge / join & apply dengan lambda
C3.4 · C3.5

Data bisnis nyata jarang berada dalam satu tabel. Kita sering perlu menggabungkan dua DataFrame — misalnya, tabel BPRS dengan tabel benchmark OJK per provinsi. Inilah fungsi merge().

pd.merge() — Menggabungkan Dua DataFrame

Python · membuat DataFrame kedua (benchmark OJK)
# DataFrame benchmark OJK per provinsi (buat manual untuk latihan)
benchmark = pd.DataFrame({
    'provinsi': ['DKI Jakarta', 'Jawa Barat', 'Jawa Timur',
                 'DI Yogyakarta', 'Jawa Tengah', 'Banten'],
    'benchmark_npf': [3.0, 3.5, 3.2, 2.8, 3.1, 2.9],
    'benchmark_car': [16, 15, 15, 16, 15, 16],
    'wilayah_ojk'  : ['Kanwil I', 'Kanwil II', 'Kanwil III',
                      'Kanwil IV', 'Kanwil IV', 'Kanwil I']
})
Python · pd.merge() — 4 jenis join
# INNER JOIN — hanya baris yang ada di KEDUA DataFrame
df_inner = pd.merge(df, benchmark, on='provinsi', how='inner')
print(f"Inner: {len(df_inner)} baris")  # hanya provinsi yang ada di benchmark

# LEFT JOIN — semua baris df, benchmark NaN jika tidak ada pasangan
df_left = pd.merge(df, benchmark, on='provinsi', how='left')
print(f"Left:  {len(df_left)} baris")   # tetap 20 baris

# Analisis: BPRS yang NPF-nya melebihi benchmark OJK
df_left['status_npf'] = df_left.apply(
    lambda r: '⚠️ Melebihi Benchmark' if r['npf_persen'] > r['benchmark_npf']
              else '✅ Di Bawah Benchmark',
    axis=1
)
print(df_left[['nama_bprs', 'npf_persen', 'benchmark_npf', 'status_npf']])
Inner: 12 baris ← hanya provinsi yang ada di tabel benchmark Left: 20 baris ← semua BPRS dipertahankan nama_bprs npf_persen benchmark_npf status_npf 0 BPRS Al-Amin 2.1 3.0 ✅ Di Bawah Benchmark 5 BPRS Artha Surya 4.1 3.5 ⚠️ Melebihi Benchmark 14 BPRS Muamalah Sejahtera 4.3 NaN NaN ...
how=Baris yang dipertahankanAnalogi SQL
'inner'Hanya yang ada di kedua tabelINNER JOIN
'left'Semua baris kiri, match dari kanan (NaN jika tidak ada)LEFT JOIN
'right'Semua baris kanan, match dari kiriRIGHT JOIN
'outer'Semua baris dari kedua tabelFULL OUTER JOIN

apply() dengan lambda — Kolom Kustom

.apply() menjalankan fungsi pada setiap baris (axis=1) atau kolom (axis=0). Dengan lambda, kita bisa membuat logika transformasi singkat dalam satu baris.

Python · apply + lambda untuk klasifikasi
# Klasifikasi kesehatan BPRS berdasarkan NPF
df['kategori_npf'] = df['npf_persen'].apply(
    lambda x: 'Sangat Sehat'  if x < 2   else
              'Sehat'         if x < 3   else
              'Cukup Sehat'   if x < 4   else
              'Perlu Perhatian'
)

# Hitung usia BPRS
df['usia_tahun'] = 2026 - df['tahun_berdiri']

# Kategorikan ukuran BPRS berdasarkan total aset
df['skala'] = df['total_aset_juta'].apply(
    lambda x: 'Besar'   if x >= 80000  else
              'Menengah' if x >= 45000  else
              'Kecil'
)

df[['nama_bprs', 'usia_tahun', 'kategori_npf', 'skala']].head(5)
nama_bprs usia_tahun kategori_npf skala 0 BPRS Al-Amin 25 Sehat Menengah 1 BPRS Berkah Syariah 21 Cukup Sehat Kecil 2 BPRS Mandiri Sejahtera 28 Sangat Sehat Besar 3 BPRS Amanah Insani 23 Cukup Sehat Menengah 4 BPRS Mitra Mentari 19 Sangat Sehat Menengah
💡 np.where() vs apply(): Untuk kondisi sederhana 2 cabang, np.where(kondisi, nilai_true, nilai_false) lebih cepat dari apply(). Gunakan apply(lambda) untuk logika multi-cabang yang lebih kompleks.

B
4 baris — karena loc bersifat inklusif di kedua ujung (baris 2, 3, 4, 5)
C
5 baris — karena iloc dan loc menggunakan aturan yang sama
D

✅ Benar! Jawaban B. df.loc[2:5] mengembalikan 4 baris (index 2, 3, 4, dan 5) karena loc inklusif di kedua ujung. Berbeda dengan df.iloc[2:5] yang hanya mengembalikan 3 baris (posisi 2, 3, 4).
Pertanyaan 2 dari 3
Bu Nisa ingin menambahkan kolom baru ke DataFrame BPRS yang berisi rata-rata NPF provinsi untuk setiap baris (bukan mengecilkan jumlah baris). Operasi yang tepat adalah:
A
df.groupby('provinsi')['npf_persen'].mean()
B
df.groupby('provinsi')['npf_persen'].transform('mean')
C
df.groupby('provinsi').agg({'npf_persen': 'mean'})
D
df.merge(df.groupby('provinsi')['npf_persen'].mean(), on='provinsi')
✅ Benar! Jawaban B. .transform('mean') mengembalikan Series sepanjang DataFrame asli (20 baris), sehingga bisa langsung dijadikan kolom baru. Opsi A dan C mengecilkan DataFrame menjadi satu baris per provinsi. Opsi D bisa bekerja tapi jauh lebih verbose.
Pertanyaan 3 dari 3
Pak Rizal ingin menggabungkan tabel BPRS (20 baris) dengan tabel benchmark OJK (6 baris, berisi data untuk 6 provinsi dari 9 provinsi di dataset). Ia ingin mempertahankan semua 20 BPRS meski ada BPRS yang provinsinya tidak ada di tabel benchmark. Jenis merge yang tepat adalah:
A
pd.merge(df, benchmark, on='provinsi', how='inner')
B
pd.merge(df, benchmark, on='provinsi', how='right')
C
pd.merge(df, benchmark, on='provinsi', how='left')
D
pd.merge(df, benchmark, on='provinsi', how='outer')
✅ Benar! Jawaban C. how='left' mempertahankan semua baris DataFrame kiri (df = 20 BPRS). Kolom benchmark akan NaN untuk BPRS yang provinsinya tidak ada di tabel benchmark. Inner join (A) akan membuang BPRS dari provinsi yang tidak ada di benchmark.
