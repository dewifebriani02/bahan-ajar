🏥 Kelompok 1 · Layanan Medis & RS Syariah

RS Islam As-Syifa

Analisis klaim BPJS vs Asuransi Swasta, utilisasi poli spesialis, dan perputaran obat farmasi.

🎯 Fokus Praktikum: Gunakan pd.merge() untuk menghubungkan tabel transaksi dengan master poli berdasarkan key kode_poli. Lakukan groupby poli & penjamin serta filter klaim yang berstatus ditolak/pending.
Kolom Tabel Transaksi (8.500 Baris):
id_transaksi id_pasien nama_pasien gender usia tgl_masuk kode_poli jenis_layanan biaya_tindakan biaya_obat_farmasi biaya_kamar total_tagihan penjamin status_klaim diskon_persen
Kolom Master Poli (8 Baris):
kode_poli nama_poli dokter_spesialis tarif_konsultasi_dasar
⬇️ Unduh Transaksi RS 8.500 Baris (1.2 MB) ⬇️ Unduh Master Poli Master (1 KB)
Python / Pandas Quick Start (Kelompok 1) 
import pandas as pd

# 1. Membaca dataset
df_trans = pd.read_csv('kel1_rs_transaksi_layanan.csv')
df_poli = pd.read_csv('kel1_rs_master_poli.csv')

# 2. Merge data transaksi dengan master poli
df_rs = pd.merge(df_trans, df_poli, on='kode_poli', how='left')

# 3. Analisis agregasi per poli
rekap = df_rs.groupby('nama_poli').agg(
    total_pasien=('id_transaksi', 'count'),
    total_pendapatan=('total_tagihan', 'sum'),
    rata_biaya_obat=('biaya_obat_farmasi', 'mean')
).reset_index()
print(rekap)

Barakah Artisan Bakery & Cafe

Analisis profit margin per varian cake, performa jam kasir teramai, dan efektivitas promo diskon.

🎯 Fokus Praktikum: Lakukan pd.merge() antara transaksi kasir dengan master menu menggunakan key kode_menu. Hitung total margin profit kotor dan rekap penjualan per outlet dan metode bayar.
Kolom Transaksi Kasir (10.000 Baris):

Kolom Master Menu (10 Baris):

⬇️ Unduh Transaksi Kasir 10.000 Baris (1.1 MB) ⬇️ Unduh Master Menu Master (1 KB)
Python / Pandas Quick Start (Kelompok 2) 
import pandas as pd

df_kasir = pd.read_csv('kel2_fnb_transaksi_kasir.csv')
df_menu = pd.read_csv('kel2_fnb_master_menu.csv')

# Gabungkan dengan Master Menu
df_fnb = pd.merge(df_kasir, df_menu, on='kode_menu', how='left')

# Rekap margin dan omset per kategori produk
laporan_menu = df_fnb.groupby('kategori').agg(
    total_struk=('id_struk', 'count'),
    total_omset=('total_netto', 'sum'),
    total_margin=('margin_profit', 'sum')
).reset_index()
print(laporan_menu)
